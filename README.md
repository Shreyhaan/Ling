# Ling

This repository currently contains the **Contact-Admixture Atlas of Language Evolution** pilot scaffold in [`linguistic-admixture-atlas/`](linguistic-admixture-atlas/).

Start there for the South/Central Asia Glottolog + Grambank + PHOIBLE feasibility pipeline:

```bash
cd linguistic-admixture-atlas
python src/build_language_master.py
python src/make_sample_map.py
```
